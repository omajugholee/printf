## Naruto Arcade

A tiny terminal arcade game where you dodge falling Akatsuki characters as Naruto.

### Build

```sh
gcc -Wall -Wextra -Werror -pedantic -std=gnu89 naruto_arcade.c -o naruto_arcade
```

### Play

```sh
./naruto_arcade
```

Controls:
- `A` / `D` to move left or right.
- `Q` to quit.
